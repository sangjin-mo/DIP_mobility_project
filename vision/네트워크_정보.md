# 비전(VIS) 시스템 네트워크 정보

> 작성일: 2026-08-24
> 목적: 테스트·연동 작업 중 필요한 IP·포트를 한 곳에서 바로 찾아보기 위한 문서.
> 이 문서는 각 기능 `config.py`에 이미 박혀 있는 값들을 그대로 옮겨 적은 것뿐입니다 — IP가 바뀌면

| `8002` | 촬영 제어 API | `image_transfer/system/pi_agent/capture.py` | 대시보드가 START/STOP 시 `POST /capture/start` · `/capture/stop` 호출, `GET /capture/state`로 확인 |

| `8010` | 정지 표지판 인식 상태 API | `stop_sign/system/pi2_detector/state_api.py` | `POST /vehicle-state`(수동 테스트 편의용, 평소엔 아래처럼 폴링이 대신함) |

## 4. IP가 바뀌었을 때 고쳐야 할 파일 목록

라즈베리파이는 재부팅 시 DHCP로 IP가 바뀔 수 있습니다. 2호기 IP가 바뀌면 아래를 전부 맞춰야 합니다.

- [ ] `image_transfer/system/pc_server/config.py`의 `PI_HOST`
- [ ] `image_transfer/system/testguide/*.ps1` 상단 `$PI_IP`
- [ ] `stop_sign/system/testguide/*.ps1` 상단 `$PI_IP`
- [ ] (이 문서) 위 §1 표

central 서버(PC) IP가 바뀌면 아래를 맞춰야 합니다.

- [ ] `image_transfer/system/pi_agent/config.py`의 `SERVER_HOST`
- [ ] `mediapipe/system/pi2_gesture/gesture_config.py`의 `DASHBOARD_URL`
- [ ] (이 문서) 위 §1 표
